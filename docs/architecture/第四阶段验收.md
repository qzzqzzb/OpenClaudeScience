### 3. LangGraph Stream Event 映射

代码：

```text
ui/src/lib/langgraph-runtime-event-mapper.ts
ui/tests/langgraph-runtime-event-mapper.test.mts
```

完成映射：

```text
messages/messages-tuple assistant chunk -> message_delta
assistant tool_calls -> tool_call
tool message -> tool_result
__interrupt__ -> interrupt
values/updates -> state
error -> error
```

未强行映射：

```text
run_started
message_completed
done
```

原因：

- 当前 LangGraph raw stream chunk 不稳定表达完整 run 生命周期。
- 生命周期应由 submit / join / cancel 控制层生成。

## 当前架构状态

当前主链路仍是：

```text
Chat UI
  -> useChat / useAgentRuntimeStream
  -> LangGraph SDK useStream
  -> LangGraph backend
  -> DeepAgents
```

第四阶段新增旁路是：

```text
AgentRuntimeRunInput
  -> AgentRuntimeProtocolProvider
  -> AgentRuntimeRunEvent
```

这条旁路已经具备 Mock 和 LangGraph 组合验证能力，但还没有接管产品主链路。

## 主链路接入进展

已补充：

```text
ClientAgentRuntimeAdapter.subscribeProtocolEvents()
LangGraphAgentRuntimeAdapter
  -> WebRemoteAgent raw stream event
  -> mapLangGraphStreamEventToRuntimeEvents()
  -> AgentRuntimeRunEvent
useStreamEventLayer
  -> protocolEvents
useAgentRuntimeStream
  -> ClientAgentRuntimeAdapter.submitStreamRun()
  -> ClientAgentRuntimeAdapter.stopStreamRun()
```

这意味着现有聊天链路仍然保留 LangGraph `useStream` 的稳定行为，但 runtime facade 已经开始向 UI/Hook 暴露中立 protocol event。

当前仍未做：

```text
没有用 AgentRuntimeProtocolProvider 替换 LangGraph SDK useStream
没有改变 submit/retry/resume/checkpoint/durability 语义
```
