# 第三阶段验收：Agent Runtime Adapter 化

## 结论

第三阶段已完成“前端 Agent Runtime Adapter 边界收口”。

本阶段没有替换 LangGraph / DeepAgents，也没有接入 OpenCode。完成目标是：让 UI 和业务 Hook 不再到处直接理解 LangGraph 的 thread/run/stream 细节，而是通过明确的 runtime adapter / stream facade 访问。

## 已完成

### Runtime 入口

- `useAgentRuntime()` 成为 React 页面层唯一 runtime context 入口。
- `AgentRuntimeProvider` / `AgentRuntimeContext` 命名已从 RemoteAgent 收口到 AgentRuntime。
- `LangGraphAgentRuntimeAdapter` 是当前唯一 concrete adapter。
- `WebRemoteAgent` 已被限制在 `LangGraphAgentRuntimeAdapter` 内部。

### Thread 能力

以下能力已走 `ClientAgentRuntimeAdapter`：

- `resolveAssistant()`
- `searchThreads()`
- `getThread()`
- `getThreadState()`
- `getThreadHistory()`
- `getPendingRunInputPreview()`
- `updateThreadMetadata()`
- `updateState()`

页面层不再直接调用 `client.threads.*`。

### Stream / Run 能力

`useAgentRuntimeStream()` 是当前 LangGraph `useStream()` 的唯一 facade。

已收口的 run 入口：

- `submitRun()`
- `stopRun()`
- `submitSendMessageRun()`
- `submitRetryMessageRun()`
- `submitSingleStepRun()`
- `submitRerunSubagentStepRun()`
- `submitContinueRun()`
- `submitResolveThreadRun()`
- `submitResumeInterruptRun()`
- `stopCurrentRun()`

`useChat.ts` 不再直接调用 `stream.submitRun(..., { intent })` 或 `stream.stopRun(...)`。

### Contract

新增中立 contract：

```text
ui/src/lib/agent-runtime-runs.ts
```

包含：

- `AgentRuntimeRunIntent`
- `AgentRuntimeStopIntent`
- `AgentRuntimeControlIntent`
- `AgentRuntimeRunDescriptor`
- `AgentRuntimeStopDescriptor`

这些类型不依赖 React，也不依赖 LangGraph。

## 保留边界

这些不是遗漏，是第三阶段刻意保留的边界：

- `useAgentRuntimeStream()` 内部仍使用 LangGraph `useStream()`。
- `LangGraphAgentRuntimeAdapter` 内部仍使用 `WebRemoteAgent`。
- `agent-runtime.ts` 内部仍使用 LangGraph `client.threads.*`。
- `project-runtime-client.ts` 仍使用 LangGraph `client.threads.*` / `client.runs.*`，负责 `runtimeUrl` 远端同步。
- UI 仍使用 LangGraph 的 `Message` / `Assistant` / `Thread` 等数据类型。

## 不在第三阶段做

- 不接 OpenCode。
- 不接 mock runtime。
- 不改 LangGraph run payload。
- 不改 checkpoint / command / interruptBefore / interruptAfter / durability。
- 不替换 runtime event 协议。

这些应放到下一阶段：先定义跨 runtime run/event/file/workspace 协议，再接第二 provider。

## 人工测试用例

建议测试：

1. 打开工作台，进入已有项目会话。
2. 发送一条普通消息，例如“你好”。
3. 在回复过程中点击停止。
4. 对一条 human 消息执行重试。
5. 触发单步运行，如果界面有单步按钮，验证能继续到工具前/后。
6. 如果出现 interrupt，提交恢复值，验证能继续。
7. 切换会话，验证历史消息、标题、归档/恢复仍正常。
8. 有远端 runtime 时，验证运行中状态和最终消息能同步刷新。
