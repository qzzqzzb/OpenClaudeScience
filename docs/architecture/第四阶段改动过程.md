# 第四阶段改动过程

## 起点判断

第三阶段已经完成：

- 前端 Agent Runtime Adapter 边界收口。
- `useChat.ts` 的 run 控制入口收口到 `useAgentRuntimeStream()`。
- coordinator / runtime / RemoteGraph / DeepAgents / Skills / MCP / subagents 关系图已补齐。

第四阶段进入：

```text
Runtime Protocol 标准化
  -> MockRuntimeProvider 验证
    -> OpenCodeRuntimeAdapter 评估
```

## 4.1 新增客户端中立 Runtime Protocol types

目标：

- 定义客户端可引用的跨 runtime 协议。
- 不依赖 React、LangGraph SDK、DeepAgents、OpenCode。
- 为后续 MockRuntimeProvider 和 OpenCodeRuntimeAdapter 提供稳定类型。

改动范围：

```text
ui/src/lib/agent-runtime-protocol.ts
docs/architecture/第四阶段RuntimeProtocol设计.md
docs/architecture/后续改造.md
```

新增：

```text
AgentRuntimeProviderKind
AgentRuntimeRunInput
AgentRuntimeRunEvent
AgentRuntimeMessage
AgentRuntimeWorkspaceContext
AgentRuntimeSkillContext
AgentRuntimeMcpToolContext
AgentRuntimeAttachment
AgentRuntimeErrorShape
```

标准事件：

```text
run_started
message_delta
message_completed
tool_call
tool_result
interrupt
state
artifact
error
done
```

谨慎点：

- 本轮不改主聊天链路。
- 本轮不接 mock runtime。
- 本轮不接 OpenCode。
- 本轮不改 LangGraph payload / checkpoint / interrupt / durability。

验证：

```text
npx tsc --noEmit --pretty false
npm run lint
git diff --check
```

验证结果：

- TypeScript 通过。
- lint 无新增 error。
- lint 仍为既有 5 个 warning。
- `git diff --check` 通过，仅有 Windows 换行转换 warning。

## 4.2 新增 Mock Runtime 事件生成器骨架

目标：

- 用本地 mock runtime 验证 `AgentRuntimeRunInput` / `AgentRuntimeRunEvent` 是否能表达基本 Agent 运行过程。
- 先不接入主聊天 UI，不替换 LangGraph `useStream`。
- 先覆盖 success / tool_call / interrupt / error 四类最小场景。

改动范围：

```text
ui/src/lib/mock-agent-runtime.ts
ui/tests/mock-agent-runtime.test.mts
ui/package.json
ui/src/lib/agent-runtime-protocol.ts
docs/architecture/第四阶段改动过程.md
```

新增能力：

```text
MockRuntimeProvider
createMockRuntimeEvents()
streamMockRuntimeRun()
streamMockRuntimeEvents()
collectMockRuntimeEvents()
```

事件覆盖：

```text
run_started
state
message_delta
tool_call
tool_result
message_completed
interrupt
error
done
```

谨慎点：

- 本轮不修改 `useChat.ts`。
- 本轮不修改 `agent-runtime.ts` 的 LangGraph 主实现。
- 本轮不接 OpenCode。
- 本轮不修改 Python `agent_graph.py`。
- Mock runtime 仅作为旁路协议验证工具。

验证：

```text
npm run test:mock-runtime
npx tsc --noEmit --pretty false
npm run lint
git diff --check
```

验证结果：

- `npm run test:mock-runtime` 通过，3 个测试全部通过。
- TypeScript 通过。
- lint 无新增 error。
- lint 仍为既有 5 个 warning。
- `git diff --check` 通过，仅有 Windows 换行转换 warning。
