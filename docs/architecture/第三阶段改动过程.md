## 3.1 新增前端 Agent Runtime Adapter 入口

目标：

- 把当前 LangGraph / WebRemoteAgent 包成一个 concrete runtime adapter。
- 新增 `useAgentRuntime()` 作为后续迁移入口。
- 保留 `useRemoteAgent()` 兼容主聊天链路，避免一次性改崩 `useChat()`。

新增：

```text
ui/src/lib/agent-runtime.ts
```

核心类型：

```text
AgentRuntimeProvider = "langgraph"
ClientAgentRuntimeAdapter
LangGraphAgentRuntimeAdapter
createAgentRuntimeAdapter()
```

当前 adapter 能力：

```text
resolveAssistant()
searchThreads()
updateThreadMetadata()
updateState()
subscribe()
getStreamSubmitOptions()
client / legacyAgent 兼容出口
```

改动：

```text
ui/src/providers/ClientProvider.tsx
  RemoteAgentProvider 内部改为创建 ClientAgentRuntimeAdapter。

ui/src/providers/AgentRuntimeContext.ts
  新增 Agent Runtime context。
  新增 useAgentRuntime()。
  保留 useRemoteAgent() 和 useClient()，兼容未迁移代码。
```

结果：

- 第三阶段有了明确 runtime 入口。
- 当前 concrete provider 仍是 LangGraph，不改变现有行为。
- 后续 OpenCode / mock runtime 可以挂到 `createAgentRuntimeAdapter()`。

## 3.2 迁移低风险 thread 操作到 AgentRuntimeAdapter

迁移范围：

```text
ui/src/app/hooks/useThreads.ts
ui/src/app/components/ThreadList.tsx
ui/src/app/config/components/ArchivedThreadsCard.tsx
ui/src/app/page.tsx
```

具体改动：

- `useThreads()` 改为通过 `agentRuntime.searchThreads()` 查询会话。
- `ThreadList` 的归档操作改为 `agentRuntime.updateThreadMetadata()`。
- `ArchivedThreadsCard` 的恢复操作改为 `agentRuntime.updateThreadMetadata()`。
- `HomePageInner` 的 assistant 解析改为 `agentRuntime.resolveAssistant()`。

暂不迁移：

```text
ui/src/app/hooks/useChat.ts
@langchain/langgraph-sdk/react useStream()
runtime live stream
interrupt resume
run stop/retry
thread snapshot/history
```

原因：

- 这些是聊天主链路。
- 需要先定义 runtime event protocol，再迁移。
- 不能和 provider 入口改造混在一个大改里。

当前结果：

- 会话列表、归档、恢复、assistant resolve 已走第三阶段 adapter 入口。
- 主聊天行为保持原样。

验证：

```text
npx tsc --noEmit --pretty false
npm run lint
```

验证结果：

- TypeScript 通过。
- lint 无新增 error。
- lint warning 从原来的 7 个降到 5 个，因为 `ClientProvider.tsx` 拆出了 context/hooks。

## 3.3 迁移 thread state / history / updateState 到 AgentRuntimeAdapter

目标：

- 继续压缩 UI / Hook 对 `client.threads.*` 的直接依赖。
- 先迁移普通线程读写能力，不动 `useStream()` 主聊天流。
- 保持现有 LangGraph SDK 行为不变，只改变调用入口。

新增 adapter 能力：

```text
getThread()
getThreadState()
getThreadHistory()
getPendingRunInputPreview()
```

改动范围：

```text
ui/src/lib/agent-runtime.ts
ui/src/app/hooks/useThreads.ts
ui/src/app/hooks/useChat.ts
```

具体改动：

- `useThreads()` 中主服务的 thread state 读取改为 `agentRuntime.getThreadState()`。
- `useThreads()` 中 pending run input preview 改为 `agentRuntime.getPendingRunInputPreview()`。
- `useChat()` 的 thread snapshot 主服务读取改为 `agentRuntime.getThreadState()`、`agentRuntime.getThread()`、`agentRuntime.getThreadHistory()`。
- `useChat()` 的 files / threadSkills 状态更新改为 `agentRuntime.updateState()`。
- `useChat()` 的标题保存改为 `agentRuntime.updateThreadMetadata()`。

暂不迁移：

```text
@langchain/langgraph-sdk/react useStream()
runtimeClient.threads.* 临时运行时同步
runtime live stream
run stop / retry / interrupt / resume
```

原因：

- `useStream()` 和 run 操作是聊天主链路，需要先定义 runtime event protocol。
- `runtimeClient` 当前表示项目 runtime 的临时状态同步，不和主 Agent Runtime Adapter 在这一小步里混拆。

验证：

```text
npx tsc --noEmit --pretty false
npm run lint
```

验证结果：

- TypeScript 通过。
- lint 无新增 error。
- lint 仍为既有 5 个 warning。

## 3.7 抽出 ProjectRuntimeClient，收口项目 runtime 同步分支

目标：

- `runtimeUrl` 对应的是项目 runtime / local runtime 同步分支，不是主 Agent Runtime。
- 这条分支之前在 `useChat.ts`、`useThreads.ts` 里直接 `new Client()` 并调用 `runtimeClient.threads.*`、`runtimeClient.runs.*`。
- 本轮先把这些 LangGraph SDK 细节收口到单独 wrapper，保持行为不变。

新增：

```text
ui/src/lib/project-runtime-client.ts
```

新增能力：

```text
createProjectRuntimeClient()
ProjectRuntimeClient
getThread()
getThreadState()
getThreadHistory()
getPendingRunInputPreview()
listRuns()
joinRunStream()
```

改动：

- `useChat.ts` 中项目 runtime 的 run list / join stream / thread state / thread history 改走 `ProjectRuntimeClient`。
- `useThreads.ts` 中项目 runtime 的 thread state / thread history 改走 `ProjectRuntimeClient`。
- `pending-run-input.ts` 的 helper 入参从完整 LangGraph `Client` 缩小为只需要 `runs.list()` 能力。

当前效果：

- 页面 Hook 不再直接创建项目 runtime 的 LangGraph `Client`。
- 页面 Hook 不再直接调用 `runtimeClient.threads.*`、`runtimeClient.runs.*`。
- 主 Agent Runtime 与项目 runtime 同步分支在命名上分开，避免团队误以为它们是同一个 adapter。

验证：


验证结果：

新增：

```text
ui/src/app/hooks/useAgentRuntimeStream.ts
```

当前实现：

```text
useAgentRuntimeStream()
  -> agentRuntime.client
  -> LangGraph useStream()
```

- `useAgentRuntimeStream()` 内部仍然委托原来的 LangGraph `useStream()`。
