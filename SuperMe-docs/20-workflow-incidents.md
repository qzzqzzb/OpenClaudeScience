# Workflow Incidents

This document records cases where the user was dissatisfied with Codex behavior or where Codex behavior exposed a workflow gap.

Incidents are a triage queue, not policy. During review, decide whether each incident should lead to a global policy update, project policy update, documentation content update, skill/tooling update, or no durable change.

## Status Values

- `open`: recorded, not reviewed yet.
- `triaged`: reviewed and assigned an action.
- `resolved`: durable action completed or explicitly declined.
