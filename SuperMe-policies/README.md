# SuperMe Policies

This directory stores behavior rules for Codex. Policies are not project history and should not record experiment results, implementation notes, or one-off facts.

## Files

| File | Purpose |
| --- | --- |
| [constitution.md](constitution.md) | Global rules that should apply across projects. |
| [default-workflow.md](default-workflow.md) | Single default workflow policy for development, research, rjob, documentation, and reporting behavior. |
| [anti-patterns.md](anti-patterns.md) | Codex behaviors that are explicitly discouraged or forbidden. |
| [user-preferences.md](user-preferences.md) | Stable user style and collaboration preferences. |
| [project-policy.md](project-policy.md) | Project-local policy additions that should not be pushed into global SuperMe by default. |
| [policy-changelog.md](policy-changelog.md) | Timeline of durable policy changes accepted during triage. |

## Policy Criteria

A rule belongs here only if it should affect future behavior. Use `SuperMe-docs/` for state such as current experiment status, decisions already made, handoffs, and results.

Good policies are:

- durable across multiple tasks;
- actionable by Codex;
- specific enough to validate;
- short enough to keep in working context;
- traceable to a reason or incident when added.

Avoid policies that are merely preferences from a single moment, broad aspirations, or facts that will become stale.
