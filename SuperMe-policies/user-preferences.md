# User Preferences

Stable collaboration preferences for this Codex environment.

- Prefer concise final answers.
- Prefer concrete file/document updates over repeated verbal reminders.
- Prefer explicit failure and uncertainty over hidden recovery.
- Prefer durable workflow improvements after repeated agent mistakes.
- Prefer reusable skills for stable procedures and policies for behavior rules.
- Prefer project docs for state, decisions, experiment records, and handoffs.

Do not add momentary preferences here until they have clear future value.
